# Optional extras

Heavy dependencies are declared in `pyproject.toml` under
`[project.optional-dependencies]`, not duplicated here.

```bash
pip install -e ".[dev]"    # pytest
pip install -e ".[nwb]"    # h5py — local Allen NWB via python -m tpl.io.allen --nwb
pip install -e ".[ibl]"    # ONE-api — optional; extract itself is numpy-only
pip install -e ".[full]"   # allensdk, mne, giotto-tda, scikit-dimension, ONE-api
                           # (allensdk: Python 3.11)
```

The core (`numpy`, `scipy`, `ripser`) installs without this file.
`tpl.io.allen.read_ecephys_nwb` needs h5py only. Do not import allensdk on
Python 3.14; pass `--nwb` after downloading the file with curl.
